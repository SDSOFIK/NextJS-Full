---------------------- what is a next js  ---------------

Next.js হলো React-এর একটি framework, যা দিয়ে দ্রুতগতির website এবং web application তৈরি করা যায়।

react দিয়ে web site বানানো পাশাপাশি next js এর কিছু bul in feature থাকে 

1. Routing: সহজে Home, About, Contact page তৈরি করা।
2. SEO: প্রতিটি page-এর title ও metadata সেট করা।
3. Rendering: Server-side rendering (SSR) এবং static rendering-এর সুবিধা।
4. Backend: API Routes ও Route Handlers দিয়ে backend functionality তৈরি করা।
4. Optimization: Image ও font optimization-এর সুবিধা।
